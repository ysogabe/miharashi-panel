## 現在の対応状況

| 項目 | 状況 |
|---|---|
| 前後の画面への切り替え、決定、項目移動、メニュー | 実装済み。旧設計の P2 の最小版から拡張済み |
| メニューからの画面選択、画面に応じたボタン表示 | v0.2.0 で対応。実機で確認した操作は、メニューの開閉、選択移動、行のタップでの画面切り替え、画面に応じた説明の変更 |
| 自動巡回の状態表示、一時停止からの残り時間 | v0.2.0 で対応。実機で状態表示と残り時間のカウントを確認済み |
| 自動巡回の固定・再開 | 実装済み。LP の実機画像で固定中の表示を確認できる。再開後の遷移を含む確認方法は [使い方](USAGE.md) に記載 |
| モニターの消灯・点灯・自動 | 実装済み。本体が Home Assistant の設定を変更し、取得した状態を操作盤に表示 |
| 自動起動、全画面表示、無操作時の低輝度フリップ時計 | 実装済み。起動には HOME の指定または起動用の権限が必要 |
| 照度による自動調光・暗闇での本体モニター消灯 | 実装済み。対応センサーが必要。使用中のShow 5でLight Sensorの登録とAndroidで31 lxの受信を確認。アプリでの照度変化・明るさ・本体自動消灯の実機試験は別途必要 |
| 夜間の時刻に応じた減光 | 時刻に応じた機能はなし。照度と待機時計で減光 |
| ほかの Android 端末での動作 | 未確認 |
| LP の管理移管 | このリポジトリに公開用ファイルを用意。移管作業時点では新 URL への公開は未確認。旧ページの削除・リンク更新は [miharashi #64](https://github.com/ysogabe/miharashi/issues/64) |

「実装済み」はコードがあることを表します。実機での確認結果や長時間の安定性は分けて記録し、テストを追加しただけで実機確認済みとは扱いません。

## 本体側の文書との役割分担

このリポジトリでは Android アプリと操作パネル LP を管理します。サーバー側の API の正式仕様、Miharashi 本体の設定と運用は、本体側で管理します。

- [Miharashi の使い方](https://github.com/ysogabe/miharashi/blob/main/docs/USAGE.md)
- [panel API の仕様と設計経緯](https://github.com/ysogabe/miharashi/blob/main/docs/panel/DESIGN.md)（§5.2 が API の参照先）

本体側の設計書には初期の画面案や段階ごとの記録もあります。アプリの現在の画面構成は、このリポジトリの [技術設計](DESIGN.md) を参照してください。
